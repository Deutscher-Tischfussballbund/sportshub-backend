# sportshub-backend

## Commits & tickets (hard requirement)

- **Every commit must reference a YouTrack ticket** from project **SPO** (Sportshub, http://youtrack.dtfb.de), e.g. `feat(category): eligibility profile (SPO-61)`. PR titles/descriptions carry the ticket too. Mandatory since 2026-09-25.
- No ticket fits? Ask which one to use (or whether to create one) — never commit without one, never invent an ID.
- Tickets are rough, broad-view context, not specs: the agreed implementation is often several iterations further than the ticket text.
